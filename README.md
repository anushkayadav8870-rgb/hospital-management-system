# PulseCare Hospital Management System (HMS)

An educational, full-stack hospital management web application paired with a systems programming C algorithms companion suite.

## Project Structure

```
hospital-management-system/
├── client/              # React + Vite Frontend
├── server/              # Node.js + Express REST API
├── c-algorithms/        # C Algorithms & Systems Concepts
├── docs/                # Architecture & API Documentation
├── .gitignore           # Git ignore configuration
└── README.md            # Project overview
```

## Architecture
- **Frontend**: React, Vite, HTML5, CSS3, Modern JavaScript
- **Backend**: Node.js, Express.js
- **Database**: PostgreSQL
- **Security**: JWT, bcrypt
- **Algorithms Companion**: C (MinGW / GCC)
